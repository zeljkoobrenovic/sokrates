Rules of thumb, not measurements: one man-year rebuilds about 10,000 lines of main code (design, testing and coordination included), and keeping a code base alive takes about 15% of its rebuild value per year (20 man-years of rebuild value need about 3 man-years of maintenance every year). The effort figures count main code only; the token figures count all code, per scope in the table. They count only reading the source once (input tokens), not the prompts, the answers or repeated reads within a session. The write tokens price the churn (lines added + deleted) as if an AI agent wrote every changed line, with the same tokens per line, at about 3 times the read token price (output tokens cost more than input tokens). The hidden loop factor (20 by default) covers what an agent writes but does not keep: reasoning, drafts, retries and rewrites. Your changes are remembered in this browser for every report.
